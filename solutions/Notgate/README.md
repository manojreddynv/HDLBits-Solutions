<p>Create a module that implements a NOT gate.
</p><p>This circuit is similar to <a href="/wiki/wire" title="wire" class="vlgstat_link">wire</a>, but with a slight difference. When making the connection from the wire <code>in</code> to the wire <code>out</code> we're going to implement an inverter (or "NOT-gate") instead of a plain wire. 
</p><p>Use an assign statement. The <code>assign</code> statement will <i><abbr title="A change in the inputs immediately updates the output.">continuously</abbr> drive</i> the inverse of <code>in</code> onto wire <code>out</code>.
